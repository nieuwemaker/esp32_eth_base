# Info for ESP32 WROOM

## Install wled
1. Go to https://install.wled.me/ and install the latest version of WLED on the ESP32
2. Select to the WLED-AP wifi access point
3. Go to 4.3.2.1 to setup the WLED instance

## PCB help
Standard GPIO pin for the leds is 16
